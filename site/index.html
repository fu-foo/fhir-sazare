sazare

A FHIR R4 server in one binary.

SQLite inside, nothing else to set up. Every write is checked against the R4 definitions, and CI compares those checks with the HL7 FHIR validator — on the R4 examples, on copies broken on purpose, through every write path. It passes the Inferno US Core v7 and v8 API suites.

Start

macOS or Linux:

brew install fu-foo/tap/sazare
sazare-server start --demo --open

Windows:

scoop bucket add fu-foo https://github.com/fu-foo/scoop-bucket
scoop install sazare
sazare-server start --demo --open

Docker: ghcr.io/fu-foo/fhir-sazare. Everything else — configuration, search, limits, upgrades — is in the README.
