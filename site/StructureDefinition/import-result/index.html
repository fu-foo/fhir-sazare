ImportResult

The counts of an $import, on the OperationOutcome that answers it.

Canonical URL
https://sazare.dev/StructureDefinition/import-result
Kind
Extension (complex), on OperationOutcome
FHIR
R4 (4.0.1)
Definition
import-result.json (StructureDefinition)

Content

created
valueInteger, required — resources the $import stored.
errors
valueInteger, required — lines it refused. The first ones are listed as issues of the OperationOutcome, each with its line number.

Example

{
  "resourceType": "OperationOutcome",
  "issue": [
    {"severity": "warning", "code": "informational", "diagnostics": "2 resources imported, 1 error"},
    {"severity": "error", "code": "processing",
     "diagnostics": "line 3 (Patient): 'Patient.gender' is a code: a string, not a number"}
  ],
  "extension": [{
    "url": "https://sazare.dev/StructureDefinition/import-result",
    "extension": [
      {"url": "created", "valueInteger": 2},
      {"url": "errors", "valueInteger": 1}
    ]
  }]
}

Before 0.19.0 the extension's URL was http://sazare.dev/…; read both if you keep older answers.
