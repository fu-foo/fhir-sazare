$import

POST /$import: resources from an NDJSON body, each checked as any write is.

Canonical URL
https://sazare.dev/OperationDefinition/import
Level
System (POST /$import)
FHIR
R4 (4.0.1)
Definition
import.json (OperationDefinition)

Request

The body is NDJSON (Content-Type: application/fhir+ndjson): one resource per line. Each line is stored as a write would be — validated, conditional references resolved — and keeps its id. A line that can't be stored is reported; the others are stored.

curl -X POST -H 'Content-Type: application/fhir+ndjson' \
  --data-binary @resources.ndjson https://your-server/$import

Response

An OperationOutcome: a summary issue, the first refused lines as issues (each with its line number), and the counts in the import-result extension. 200 when something was stored, 400 when nothing was. Operators only when auth is on (a system-level write scope).
