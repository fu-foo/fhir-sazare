## Bundled profiles

### HL7 FHIR US Core Implementation Guide
- **What:** the complete set of 54 `StructureDefinition` profiles in `sazare-core/profiles/us-core/`
- **Source package:** `hl7.fhir.us.core` version `8.0.0`
- **Publisher:** HL7 International
- **License:** CC0-1.0 (verified in the package manifest)

Besides US Core and the R4 search parameters below, no conformance content is
embedded in the binary. Other Implementation Guides (e.g. HL7 FHIR JP Core) are
**not** bundled — load them at runtime by dropping their `StructureDefinition`
resources into a `profiles/` directory next to the binary (see the README).

### HL7 FHIR R4 element definitions
- **What:** every element of the R4 resources and complex data types (path, maximum
  cardinality, types), as `sazare-core/structure/r4.tsv`, generated by `generate.py` next
  to it; writes are checked against it
- **Source:** `profiles-resources.json` and `profiles-types.json` of HL7 FHIR R4 (4.0.1)
- **License:** CC0-1.0 (HL7 FHIR specification content)

### HL7 FHIR R4 summary elements
- **What:** the top-level elements marked `isSummary` in the R4 resource
  `StructureDefinition`s, as `sazare-core/summary-elements/r4.tsv` (type, then the
  element names), generated by `generate.py` next to it; `_summary=true` keeps them
- **Source:** `profiles-resources.json` of HL7 FHIR R4 (4.0.1)
- **License:** CC0-1.0 (HL7 FHIR specification content)

### HL7 FHIR R4 search parameters
- **What:** the R4 `SearchParameter` definitions of type token, string, date, reference,
  number and quantity, as `sazare-core/search-parameters/r4.tsv` (base type, code, type,
  expression), generated by `generate.py` next to it
- **Also:** each reference parameter's target types, as
  `sazare-core/search-parameters/targets.tsv` (generated by `targets.py`), for chains
  written without a type
- **Source:** `search-parameters.json` of HL7 FHIR R4 (4.0.1)
- **Publisher:** HL7 International
- **License:** CC0-1.0

## Base specification

This server implements **HL7 FHIR R4 (4.0.1)**. The FHIR specification material is
published by HL7 International under CC0-1.0. No restrictively licensed code
system content (e.g. SNOMED CT, LOINC) is embedded — profiles reference such code
systems by canonical URL only, which carries no redistribution obligation.
